# Ejemplo lleno — Proyecto Braille

Este ejemplo muestra cómo se ve la plantilla de proyecto cuando está completa.
Usa el mismo `preamble.tex`, `main.tex` y estructura de `secciones/` que la
plantilla vacía, pero con el contenido del trabajo Braille.

## Qué se llenó

- `config.tex`: título, autores, filiación, curso, docente, fecha, resumen y
  palabras clave.
- `secciones/01` a `12`: contenido condensado del proyecto.
- `referencias.bib`: 10 fuentes reales del trabajo.

## Nota

El trabajo completo, con todas las tablas y el texto extenso, está en
`01_Proyecto_Tesis/Proyecto_OBR_Braille_APA7.docx` y en su ZIP de Overleaf.
Este ejemplo sirve como referencia de estructura y de uso de las macros APA.

## Cómo compilar

Importa esta carpeta como ZIP en Overleaf. El `latexmkrc` fuerza XeLaTeX y
Overleaf ejecuta Biber automáticamente.

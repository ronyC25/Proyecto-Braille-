# Carpeta de figuras

Coloca aquí las imágenes del artículo (`.png`, `.jpg` o `.pdf`).

Ejemplo de uso dentro de una columna:

```latex
\begin{figure}[H]
  \centering
  \includegraphics[width=\columnwidth]{figuras/mi-figura.png}
  \caption{Título de la figura}
  \label{fig:mi-figura}
  \notaFigura{Fuente: elaboración propia.}
\end{figure}
```

En APA 7 el número y el título de la figura van **encima** de la imagen.

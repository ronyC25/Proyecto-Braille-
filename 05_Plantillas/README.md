## Inicio rápido

1. Descarga el ZIP de la plantilla que necesites.
2. En Overleaf: **New Project → Upload Project**.
3. Edita `config.tex` y los archivos de `secciones/`.
4. Agrega tus fuentes en `referencias.bib`.
5. Compila con XeLaTeX (el `latexmkrc` ya lo configura).

## Requisitos

- XeLaTeX.
- Biber.
- Overleaf ejecuta ambos automáticamente.

## Nota

Las plantillas no reemplazan la revisión del docente o asesor. Verifica siempre
las indicaciones específicas de tu curso o revista.

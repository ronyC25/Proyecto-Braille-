# Carpeta de figuras

Coloca aquí las imágenes del proyecto (`.png`, `.jpg` o `.pdf`).

Ejemplo de uso en una sección:

```latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{figuras/mi-figura.png}
  \caption{Título de la figura en cursiva}
  \label{fig:mi-figura}
  \notaFigura{Fuente: elaboración propia.}
\end{figure}
```

En APA 7 el número y el título de la figura van **encima** de la imagen.
